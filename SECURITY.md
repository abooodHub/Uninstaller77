# Security reports

Do not post credentials, unredacted operation logs, browser profile data or local databases in public issues.

Use GitHub private vulnerability reporting when available for this repository. If unavailable, contact the maintainer through the GitHub profile to arrange a private report; do not publish exploit-sensitive details while waiting.

Include the affected version, operation and a minimal isolated reproduction. Distinguish application defects from Windows permission restrictions and vendor refusals. The app must not bypass UAC, modify unrelated application identities or claim success without removal evidence.
