# Retired product features

Software Health, Install Monitor, File Shredder and System Restore implementations are archived here and excluded from the shipping application. No product action can reach them. Existing user SQLite tables/files were not dropped or rewritten.

Engine.Tests compiles these sources only to preserve the historical regression suite, including Phase12/13. Passing a historical test does not mean the removed feature exists in the product. The relocation manifest and pre-edit snapshot are in reports/FULL_CODE_AUDIT_2026_10_26 and _build/audit-snapshot-20261026.
