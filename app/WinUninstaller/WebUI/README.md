# Uninstaller 77 embedded UI

Offline React/TypeScript UI for the WPF WebView2 host. Opening Vite alone does not supply the native bridge or installed-program inventory. Normal UI never substitutes fixture data for real discovery.

```powershell
npm test
npm run lint
npm run build
node tests/render-audit.mjs
```

npm test runs current presentation cases and preserved historical helpers from tests/retired/WebUI. Historical tests do not restore their removed product features. render-audit.mjs checks component/accessibility contracts in both languages; it does not establish native visual layout or resize correctness.

The application version comes from the parent WinUninstaller.csproj via Vite. Release publish includes the resulting dist directory as wwwroot. The host maps only the local trusted app origin and validates commands in WebUiProtocol.

Use C:\Uninstaller\installer\Build-Release.ps1 for a complete Windows x64 installer. Current audit evidence is in C:\Uninstaller\reports\FULL_CODE_AUDIT_2026_10_26.
